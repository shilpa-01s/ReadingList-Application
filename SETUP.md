# Quick setup checklist

- [ ] Install Android Studio and JDK 17.
- [ ] Open this folder in Android Studio.
- [ ] Install Android SDK Platform 35 if prompted.
- [ ] Create Firebase project and register Android package `com.example.readinglist`.
- [ ] Download `google-services.json` into `app/google-services.json`.
- [ ] Enable Email/Password in Firebase Authentication.
- [ ] Create Firestore and publish the security rules in README.md.
- [ ] Sync Gradle, connect an Android device/emulator with Google Play services, and Run.

If Gradle sync fails, check that Android Studio is using JDK 17: Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK.
